# Kick Clipper
Paste a Kick or YouTube link (or direct .m3u8) -> auto-picks the loudest moments -> saves 9:16 clips to Movies/KickClips.

## Get the APK (no Android Studio needed)
1. Create a free GitHub account and a new repository.
2. Upload ALL files in this folder (keep the .github folder).
3. Open the repo > Actions > "Build APK" > wait ~5 min.
4. Download the "KickClipper-APK" artifact, unzip, install app-debug.apk on your phone (allow "install unknown apps").

## Or build locally
Open in Android Studio, then Build > Build APK(s).
